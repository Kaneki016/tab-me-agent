# Tabme visual world

Incumbent system for the web review and extension popup. Replace this file if the visual world is redesigned; do not split the difference.

## World

A paper desk with filed tabs, not a SaaS dashboard. Warm stock, ink, and a copper tab-stop. The review should feel like sorting a stack, not administering a queue.

## Type

- Display: Fraunces
- Interface: Figtree
- Data / IDs: IBM Plex Mono
- Do not fall back to Inter, Arial, Plus Jakarta Sans, or system-ui as the voice of the page

## Color

- Paper `#f3ece0`
- Ink `#1f1a14` (tinted, not `#000`)
- Soft ink `#4a4036`
- Brass `#b4532a` / `#8a3d1f`
- Moss `#3d5347` on `#d7e2d6` for status
- Danger `#8a2430`, ok `#2f5d3a`
- No purple-to-blue gradients. No gray text on colored fills.

## Layout

- Paper-tab chips for captured URLs, not cards-in-cards
- Suggestions as a checked list with hairline rules
- Approve selected is the only primary action
- Assistant sits beside the list on wide screens, below on small ones
- No eyebrow/kicker labels above headings

## Motion

Almost none. Button hover is a color shift. No bounce, no staggered card entrances.
